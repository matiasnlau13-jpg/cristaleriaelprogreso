# Cristalería El Progreso

Sitio web de la **Primera Cooperativa Obrera del Vidrio El Progreso** (Ezpeleta,
Quilmes, Buenos Aires — desde 1947).

Una sola página (`index.html`), sin dependencias ni build: todas las fotos van
embebidas. Incluye catálogo con vista previa de cada modelo y un carrito que arma
el pedido y lo envía por WhatsApp.

## Ver el sitio

Abrí `index.html` en el navegador, o publicalo con cualquiera de estas opciones.

### GitHub Pages
1. En el repo: **Settings → Pages**.
2. En **Source** elegí **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. Guardá. En 1–2 minutos queda en `https://<usuario>.github.io/cristaleria-el-progreso/`.

### Vercel / Netlify
Importá el repo y listo (no hay que configurar nada; es HTML estático).
